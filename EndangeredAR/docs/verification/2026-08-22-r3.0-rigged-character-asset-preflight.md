## Decision

**Rejected for production integration.** The supplied FBX proves that a bone-driven
animation pipeline is possible, but it does not meet the current mobile AR,
character identity, animation-set, material, or provenance gates. The FBX was
audited in an isolated temporary Unity project and was not copied into the
official repository.

No product code, scene, package, project setting, animal definition, knowledge,
chat, task, badge, or animation-control behavior was changed.

## Existing Sensen Integration Baseline

The existing character is data-driven and must remain reversible:

- `AnimalContentAssetBuilder` generates the canonical Sensen `AnimalDefinition`.
- The active model path is `Models/Sensen/sensen.glb`; its separate base-color
  texture is `Models/Sensen/sensen_basecolor.png`.
- `AnimalExperienceController` configures the experience host from the animal
  definition. `AnimalModelLoader` loads the GLB beneath a child named
  `Animal GLB Runtime Root`.
- `AnimalGestureController` is attached to the outer animal host. Rotation and
  pinch scaling therefore act on the host, independently of the model child.
- Current definition transforms are experience position `(-1.02, -0.13, 0)`,
  model offset `(0, 0.04, 0)`, Euler rotation `(0, 180, 0)`, and scale
  `(1.45, 1.45, 1.45)`.
- `DemoAppController` applies breathing and feedback motion to the outer host.
  A replacement must preserve this ownership boundary instead of embedding
  interaction logic into the imported model.

Positive findings:

- The mesh is genuinely skinned to a working Mixamo-style skeleton.
- The Taunt clip animates 28 bone paths rather than moving only the root object.
- No Animation Events, MonoScripts, custom shaders, or colliders were imported.
- Generic Rig is the appropriate starting point for this non-human character.

Blocking findings:

1. The candidate has 2,000,000 triangles and 1,016,666 vertices. This is about
   20 times the current triangle count and is unsuitable for the present mobile
   AR target without DCC retopology/decimation and a fresh performance audit.
2. Only one non-looping Taunt clip is present. There is no Idle or Eat clip, so
   the minimum R3.0 animation foundation cannot be demonstrated.
3. The visible tail geometry has no named tail bone. It cannot be independently
   animated and may deform unnaturally with the torso/hip weights.
4. Unity reports that the source mesh has no normals and recalculates them.
5. Although the FBX binary references an embedded JPEG, Unity surfaced no
   imported texture during the audit. Render previews showed an incomplete or
   broken material appearance.
6. The visual design is a generic stylized baby monkey and does not preserve the
   established Tufted Gray Langur identity of Sensen.
7. The source scale is extremely small and would require explicit normalization.
8. Asset provenance and redistribution rights are unknown.

## Required Replacement Gate

Before R3.0 integration resumes, the replacement asset should provide:

- Verifiable author/source, license, and public-repository redistribution terms.
- A recognizable Tufted Gray Langur appearance compatible with Sensen.
- A Generic skeleton with skinned body, head, limbs, hands/feet, and preferably
  a 4-8 bone tail chain.
- A mobile target of 50,000 triangles or fewer; 100,000 is the temporary hard
  ceiling for this demo unless device profiling justifies more.
- Four materials or fewer and clean, included textures no larger than 2048 px;
  1024 px is preferred for secondary maps.
- Valid normals/tangents and no importer repair warnings.
- At minimum a looping Idle plus one verified non-idle body animation. Eat is
  preferred for the existing food mission.
- No Animation Events, scripts, executable plugins, custom packages, or
  unreviewed shaders.
- A clean neutral bind pose and an explicit scale/orientation convention.

Decimating this candidate from 2,000,000 to a mobile budget while preserving
weights, facial silhouette, UVs, materials, and animation quality is DCC asset
production work, not a safe Unity import-setting adjustment. It should only be
attempted after licensing and species-identity questions are resolved.

## Animation Reuse Assessment

The Mixamo-style body hierarchy makes external body-animation retargeting
technically plausible after a clean model-only FBX and compatible animation-only
FBX files are obtained. A simple Idle could also be authored against the Generic
bone paths in Blender or Unity. Neither option fixes this candidate's mobile
mesh cost, missing tail rig, broken material import, species mismatch, or unknown
rights. Reusing the rig now would therefore create migration work around an asset
that still cannot ship. No Animator Controller was added to the product.

## Next Action

Obtain an optimized, licensed rigged Tufted Gray Langur model with Idle and Eat
clips, or commission retopology, material repair, tail rigging, and the missing
clips for an asset whose rights are known. Run the same isolated preflight before
copying any replacement into `Assets`.

Diagnostic evidence was retained in a local-only temporary directory outside
the repository for this acceptance session and was not committed.
