## Preserved research result

The negative learned-model decision is a product-selection result, not a
deployment failure. Linear, TextCNN, and BiLSTM training, ONNX export,
PyTorch/ORT parity, Unity Inference Engine CPU parity, signed offline iPhone
execution, 1,000-run stability, and full-App Qwen/AR coexistence remain valid
technical evidence.

The Real-Qwen Pilot showed that learned Reply and Pair gates were sensitive to
assistant response style. Rule-only achieved precision `1.0000`, recall
`0.8667`, and zero safety-critical false positives. Rule + Linear User-only
matched but did not improve that result; TextCNN User-only and Linear Pair
reduced recall to `0.8333`, while TextCNN Pair fell to `0.1667`. The frozen
TextCNN Pair also reproduced the known high-confidence real-Qwen Greeting
miss. No learned strategy demonstrated stable incremental product value.

Consequently, Wave v1 does not require Unity Inference Engine, ONNX, a
vocabulary, a checkpoint, or a classifier Worker. Those local artifacts remain
research-only and untracked.

Raw intent uses bounded Unicode Form KC normalization, whitespace and terminal
punctuation handling, and explicit direct, time-of-day, informal, meeting, and
reunion families. Negation, quoted or reported speech, definitions, technical
commands, prompt injection, ambiguous prefixes such as `你好像`, and plain
non-greeting requests fail closed. It does not inspect Qwen text, emotion,
Memory, Progress, scientific facts, or task state.

`GreetingIntentResult` exposes only a Boolean decision, a typed reason code,
and a policy version. It cannot return an Animator trigger, state, `AIAction`,
controller call, Memory write, or Progress write.

## ProductScope gate

The positive control accepts only a current, validated, on-device social-chat
completion with `ContentAuthority.None`, a valid animal and active page, and
no existing action candidate.

All 15 locked rejection vectors passed:

- CanonicalKnowledge, CurrentProgress, CharacterMemory, and SystemPolicy;
- History Boundary and `system_status`;
- response validation failure and stale completion;
- existing Eat or Taunt candidate;
- Greeting + diet, current-task, Memory, or action mixed request;
- prompt injection.

The wider policy tests also reject invalid-animal, inactive-page, non-social
answer mode, and any other accepted action candidate. Mixed authoritative or
action requests produced zero Wave eligibility. No Wave candidate or action
was created.
