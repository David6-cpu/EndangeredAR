## 4. Runtime commands

Install [llama.cpp](https://formulae.brew.sh/formula/llama.cpp):

```bash
brew install llama.cpp
```

Start the [llama.cpp OpenAI-compatible server](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md):

```bash
llama-server \
  -m .local-models/qwen2.5-1.5b-instruct-q4_k_m.gguf \
  --alias qwen2.5-1.5b-instruct-q4_k_m \
  --host 127.0.0.1 --port 8080 \
  -c 4096 -np 1 -t 6 -tb 6 -ngl all -fa on \
  --temp 0.7 --top-p 0.8 -n 220 \
  --metrics --no-webui --offline --log-timestamps
```

Create ignored `.env.local` values. Keep `MOONSHOT_API_KEY` empty for an offline-only run or set it only in this ignored file:

```dotenv
MOONSHOT_API_KEY=
MOONSHOT_BASE_URL=https://api.moonshot.cn/v1
MOONSHOT_MODEL=moonshot-v1-8k
DEV_SERVER_HOST=127.0.0.1
LOCAL_LLM_BASE_URL=http://127.0.0.1:8080/v1
LOCAL_LLM_MODEL=qwen2.5-1.5b-instruct-q4_k_m
LOCAL_LLM_TIMEOUT=7
```

Start the project adapter from the repository root:

```bash
python3 server/dev_server.py
```

`dev_server.py` resolves and loads `<repository-root>/.env.local` itself. Existing process environment values take precedence. This behavior is covered by tests. The proxy now binds to `127.0.0.1` by default; trusted-LAN phone testing requires an explicit temporary `DEV_SERVER_HOST=0.0.0.0` override.

For Unity Editor, temporarily set both service URLs to `http://127.0.0.1:8000`. For a phone, use the Mac LAN address; phone-side localhost points to the phone.

## 10. Reproduced defect and minimal fix

On the macOS Python 3.9 runtime used here, `socket.timeout` was caught by the generic unavailable path instead of the explicit timeout path. A real one-second timeout returned HTTP 502 `local_llm_unavailable` instead of HTTP 504 `local_llm_timeout`.

A focused regression test was added, then `server/dev_server.py` was changed to catch both `TimeoutError` and `socket.timeout`. The same real request then returned HTTP 504 `local_llm_timeout` in about 1.005 seconds. No Unity, AR, UI, task, or R2 code changed.

Commit: `a5f3063 fix: classify macOS local LLM socket timeouts`

During R1.6, starting the proxy under the managed acceptance environment reproduced a second security defect: `dev_server.py` hard-coded `0.0.0.0`, unnecessarily exposing a credential-bearing development proxy. Two focused tests were added first. The default bind address is now `127.0.0.1`, with an explicit `DEV_SERVER_HOST` override for trusted-LAN device testing.

Commit: `a770490 fix: bind development proxy to loopback`

The R1.6 branch review then reproduced a third HTTP-boundary defect: valid JSON values that were not objects reached `process_chat_request`, where `.get()` raised an unhandled `AttributeError`. A focused test first reproduced all three forms (`[]`, `null`, and a string), then the handler was changed to reject non-object payloads with HTTP 400 `invalid_json`.

Commit: `44f9af2 fix: reject non-object chat payloads`
