## Scope

R3.0.1A adds a safe device trigger for the existing Sensen Taunt animation.
The trigger is available only in the Unity Editor and Development Players. It
does not connect Animator control to AI responses, chat history, missions,
progress, rewards, badges, or unlock state. R3.0.1B performance sampling and
R3.1 AI action control have not started.

## Runtime control boundary

The existing `AnimalModelController` was narrowed and enabled as the runtime
animation controller instead of adding a second overlapping controller. It
exposes only the fixed `TryPlayTaunt()` operation and returns one of:

- `Played`
- `Busy`
- `Inactive`
- `UnsupportedAnimal`
- `MissingAnimator`
- `InvalidControllerState`

The controller uses fixed Animator hashes, requires the active `sensen`
rigged model to be in Idle, and maintains its own pending/busy state. A second
request in the trigger frame is rejected before the Animator transition is
visible. Busy clears after Taunt returns to Idle, or after a bounded failure
timeout if the requested transition never starts. Apply Root Motion remains
disabled and the AR host transform remains owned by the existing gesture and
experience controllers.

`AnimalModelLoader.TryGetCurrentModelController` resolves the controller from
the exact active runtime model root on every request. It validates the current
animal id, active root, controller ownership, and Animator ownership. The
development panel does not cache an Animator, model root, controller, or animal
definition across page or animal lifecycle changes.

## Development-only panel

`DevelopmentToolsBootstrap` creates at most one persistent overlay through
`RuntimeInitializeOnLoadMethod`. The bootstrap and panel sources are enclosed
in:

```csharp
#if UNITY_EDITOR || DEVELOPMENT_BUILD
```

The collapsed panel is a small `DEV` button in the top-right safe area. The
expanded panel reports the current animal, Animator state, last request result,
and offers only `PLAY TAUNT` and collapse. Every click re-resolves the current
loader and controller. No product Scene, user UI, `DemoAppController`, AI
service, network client, or task service was modified for the panel.

A non-Development macOS Player smoke build completed successfully. Inspection
of the compiled runtime assembly found no development bootstrap, debug panel,
development namespace, or panel labels. The smoke Player also produced no
Missing Script, null-reference, or unhandled-exception evidence.
