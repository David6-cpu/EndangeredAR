# R3.4A.3 Signed Offline iPhone Classifier Acceptance

Date: 2026-09-01

Branch under test: `codex/r3.4a2-gold-project-review`

## Decision

**R3.4A is not fully accepted. R3.4B remains closed.**

The signed offline iPhone runtime, fixed fixtures, 1,000-iteration stability,
runtime parity, lifecycle checks, and AR coexistence all produced usable
evidence. The locked candidate nevertheless failed the required real-Qwen
greeting case: a direct greeting passed deterministic and product-scope gates,
but the TextCNN predicted `NotGreeting`. The science Qwen pair was also not
recorded because the Development-only fixed-fixture matcher rejected the
latest pair. The final device result therefore contains only two of the three
required Qwen pairs.

No retraining, threshold tuning, temperature change, rule change, model
selection, Animator work, capability change, action-policy change, or formal
completion integration was performed in response to this result.

## Exit decision

The device runtime is technically viable: it is fast, stable, offline, and
consistent across runtimes. The locked model is not yet robust to the actual
language emitted by the production on-device Qwen greeting path. Because the
required real-Qwen greeting case failed and the three-pair evidence is
incomplete, `R3.4A fully accepted` is false.

Do not begin R3.4B. A future recovery must establish a new, independently
reviewed and unpolluted evaluation plan for real validated Qwen reply
variation. It must not tune the existing candidate against this Gold/device
evidence or add Gold v2 to training.
