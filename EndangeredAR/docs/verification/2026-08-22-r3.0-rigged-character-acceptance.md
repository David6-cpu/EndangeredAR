Date: 2026-08-22

## Scope

R3.0 upgrades Sensen from the legacy static GLB presentation to an optional,
animated Generic-rig prefab while preserving the original GLB as a controlled
fallback. It does not connect AI, tasks, rewards, progress, or knowledge output
to the Animator. R3.1 has not started.

## Authorization

The project owner created and supplied the source model and explicitly
authorized its unrestricted use for this project, including development,
competition demonstrations, App distribution, and repository storage. R3.0
did not push or publicly release the asset. The character remains an approved
cartoon Sensen prototype, not independently verified species-final artwork.

## Animation and prefab

The controller has one trigger, `Taunt`, and the state flow is:

`Entry -> Idle -> Taunt -> Idle`

- Idle: default, 3.0 seconds, looping, internal-bone motion
- Taunt: about 2.83 seconds, non-looping, returns by Exit Time
- Apply Root Motion: false
- Animation Events: 0
- Prefab: `Assets/Prefabs/Animals/SensenRigged.prefab`
- Hierarchy: `SensenRigged/RiggedModelRoot/OptimizedModel`

The centimeter-authored source is normalized inside `RiggedModelRoot`; the AR
Host continues to own position, rotation, pinch scaling, and page lifecycle.
The outer configuration remains `(-1.02, -0.13, 0)`, local offset
`(0, 0.04, 0)`, yaw `180`, and scale `1.45`.

## Loading compatibility

`AnimalDefinition.ModelPrefab` is optional. `AnimalModelLoader` instantiates it
first when valid, otherwise it uses the existing StreamingAssets GLB pipeline.
Invalid or renderer-less prefabs produce a warning and controlled GLB fallback.
The `animalId`, canonical knowledge, chat history schema, R1 routing, R2
grounding/citations, tasks, profile, and AR scene structure are unchanged.

## Editor performance comparison

| Metric | Legacy GLB | 100k Rigged |
| --- | ---: | ---: |
| First display | 0.759 s | 0.094 s |
| Median Editor FPS | 1631.100 | 1380.779 |
| Runtime mesh memory | 6,360,176 B | 9,953,276 B |
| Runtime texture memory | 44,739,912 B | 1,398,800 B |
| Mesh + texture | about 48.73 MiB | about 10.83 MiB |
| Total allocated snapshot | 333,541,663 B | 233,199,677 B |

The rigged candidate appeared about 0.665 seconds sooner and used about 37.9
MiB less mesh-plus-texture memory in separate Editor runs. Its no-GPU-load
median FPS was about 15.35% lower than the legacy run. These thousands-of-FPS
Editor values are directional only and do not prove mobile frame rate.

## Known limitations and decision

- The tail has no bones and does not participate in skeletal animation.
- The cartoon prototype still needs later species-specific art refinement.
- Physical-device performance and touch acceptance are blocked by Xcode
  account/provisioning setup.
- No AI action or emotion control exists; that remains R3.1 scope.

R3.0 code, asset, fallback, animation, and Editor acceptance criteria pass.
The phase is **conditionally accepted**, with physical-device performance as
the only remaining external acceptance gate. R3.1 implementation should not
begin until that device gate is completed and reviewed.
