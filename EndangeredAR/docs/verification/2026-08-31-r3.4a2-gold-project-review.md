## Signed iPhone gate

Unity exported the independent Development iOS project with zero build errors.
Xcode signing then failed before compilation because its command-line account
store reported no usable account and no provisioning profile existed for the
separate spike bundle ID.

Two existing local profiles correspond to two already installed R3.3C apps.
They were deliberately not reused because that would replace an accepted app
and violate the R3.3C boundary.

Therefore the following remain **not passed**:

- signed iPhone build and install;
- Wi-Fi/cellular-off device classification;
- 1,000 device inference stability and Worker reload;
- iPhone mean/P95 latency;
- peak incremental device memory;
- device thermal state;
- same-App coexistence with on-device Qwen, Idle, rotation, and zoom.

The 1,000-iteration Unity Editor result must not be presented as device
evidence.

## Exit decision

Human review removed the R3.4A.1 quality uncertainty without changing any Gold
label or the locked model result. The remaining blocker is a signed, isolated,
fully offline iPhone run plus same-App Qwen/AR coexistence evidence.

contracts, connect the classifier to completion, merge main, or push.
