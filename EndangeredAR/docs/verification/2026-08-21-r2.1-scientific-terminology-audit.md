## Scope and method

The audit searched tracked repository text for the requested Chinese and English names, IUCN/CITES terms, project-positioning language, and Unicode-escaped Unity scene text. Generated caches under `Library`, local secrets, and model files were not read as product content. The repository contains no tracked PPT, PDF, Word, Keynote, RTF, or RTFD files.

The baseline produced 645 matching lines across 83 files. Each line was assigned once, using the following precedence: current Sensen error, historical record, correct scientific fact, generic platform positioning, then code/test semantics.

## Corrections

The six current Sensen presentation errors were corrected in the scene builder, committed `DemoScene`, and runtime learning copy:

- `濒危等级：濒危` -> separate `IUCN：近危（NT）` and `CITES：附录 I` seed text;
- `濒危等级` -> `保护状态` in dynamic learning content;
- `濒危档案` -> `物种档案`;
- `为什么濒危` -> `为什么需要保护`.

Active user-facing positioning and AI role copy now use `野生动物保护` or `珍稀及受保护野生动物`. The formal repository title `濒危动物交互科普系统 EndangeredAR`, code identifiers, iOS camera permission wording, and historical documents were intentionally not globally renamed.

## Canonical Sensen identity

The sole knowledge source remains `content/animals/sensen.json`:

- Chinese role: 缨冠灰叶猴“森森”
- English common name: Tufted Gray Langur
- Scientific name: `Semnopithecus priam`
- IUCN: Near Threatened (`NT`, 近危), population trend decreasing
- Global population size: unknown (`known_unknown`), with no project estimate
- Distribution: southeastern India and Sri Lanka
- CITES: Appendix I, represented separately from IUCN status

The conservation answer now explicitly states that NT is not EN and that CITES Appendix I does not equal an IUCN category.
