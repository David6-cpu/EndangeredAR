# 森森真机闭环缺陷修复设计

## 目标

在不恢复 ARFoundation、不把大模型密钥写入 Unity、不重置用户历史进度的前提下，修复 iPhone 真机验收发现的四项问题：相机预览比例失真、AI 无法连接后端、任务进入即显示获奖、科普卡片观感与排版不合格。

## 范围

本轮只修改相机预览适配、后端开发连接、任务反馈状态和科普卡片 UI。保留现有模拟识别、模型加载、模型手势、动物解锁、对话历史、任务持久化与 PNG 保存流程。

不包含公网部署、第二只动物内容、ARFoundation、账号体系、相册插件和大范围场景重建。

## 相机预览

`ARImageScanController` 继续通过 `videoRotationAngle` 旋转 `RawImage`。因为旋转已交换最终显示方向，`AspectRatioFitter` 必须使用摄像头纹理原始宽高比 `width / height`，不能再次交换宽高。

预览采用 `EnvelopeParent`：等比铺满扫描内容区，允许裁切边缘，不允许非等比拉伸。扫描框和说明文字保持在预览之上，摄像头画面不参与按钮射线检测。

新增纯计算回归测试，覆盖 0、90、270 度设备方向，证明旋转后的矩形仍使用原始纹理比例。

## AI 后端连接

真机开发阶段采用 Mac 局域网代理：

- Unity `ApiConfig.baseUrl` 在开发时指向 Mac 当前局域网代理；具体地址保留在本机配置中，不写入仓库。
- 复用现有安全后端代理和 `.env.local` 中的 Moonshot 配置。
- API Key 只由后端读取，不写入 Unity 资源、日志、测试或提交记录。
- 后端监听 `0.0.0.0:8000`，提供 `/health` 和 `/chat`。
- Unity 请求失败时继续显示本地角色化 fallback，后台日志记录简短错误，界面不展示技术堆栈。

局域网地址属于开发配置；公网部署另开任务处理，不在本轮伪装成生产云端。

## 食物任务状态

持久化的 `missionCompleted` 和本轮任务反馈分开表达：

- 首次进入任务页时只显示题目和奖励说明，不显示“本轮已获得”。
- 历史已解锁徽章显示为“徽章已收藏，本轮可再次挑战”，避免被理解为刚刚发奖。
- 正确选择后才显示成功反馈。
- 已领取过奖励的重复挑战可以反馈正确答案，但积分和徽章不能重复写入。
- 错误选择只显示重试提示，不改变持久化完成状态。

任务核心定义和动物进度仓库保持不变，只补足“历史奖励”和“当前尝试”的展示状态边界。

## 科普卡片

卡片改为单列三段式竖屏结构，适配 Safe Area 内的 iPhone 17 Pro Max：

1. 角色标题区：森森头像、标题“今日认识了森森”、物种名和一句角色化短句。
2. 学习摘要区：三条短信息，分别展示栖息地/食物、今日知识和任务状态。
3. 行动与徽章区：生态守护者徽章状态、一个环保行动建议、保存按钮和返回按钮。

视觉使用浅米绿卡面、深森林绿文字、叶绿强调和低饱和金色徽章。移除大面积深色矩形、重复标题、长段落和装饰素材遮挡。所有文本框必须在 1290 x 2796 参考分辨率下不重叠。

PNG 仍通过 `ScreenCapture.CaptureScreenshotAsTexture` 捕获 `cardCaptureRect`，文件写入 `Application.persistentDataPath`。捕获区域不包含底部导航和调试路径。

## 错误处理

- 摄像头尺寸尚未就绪时保留默认比例，尺寸有效后再更新。
- 后端未启动、手机不在同一 Wi-Fi 或模型服务失败时使用本地 fallback，聊天输入恢复可用。
- 任务定义或选项缺失时不发放奖励，并保留可返回路径。
- PNG 保存失败时显示用户可理解的失败提示，不让协程中断页面交互。

## 验收

- 相机中的键盘、识别卡等物体比例自然，无横向压扁或纵向拉长。
- `/health` 可从 Mac 和同一局域网访问，真机聊天至少连续成功两轮；断网 fallback 仍可用。
- 进入任务页不会出现本轮获奖提示；正确答案后才出现成功提示，重复挑战不重复积分。
- 卡片在真机无重叠、遮挡和溢出，保存出的 PNG 非空且构图与页面一致。
- EditMode、PlayMode 全部通过，iOS 签名构建与安装成功。
