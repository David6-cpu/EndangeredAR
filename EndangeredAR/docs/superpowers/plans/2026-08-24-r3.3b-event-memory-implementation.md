# R3.3B Event-based Character Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist bounded, versioned, deterministic character milestone events after successful Progress state transitions without giving Memory or AI any business-write authority.

**Architecture:** `AnimalProgressService` commits a copy-on-write candidate first, then emits one strongly typed `AnimalProgressTransitionBatch` to an injected sink. `CharacterMemoryService` converts that trusted batch into validated, idempotent records in an independent `character-memory.json`, and exposes deterministic projections without feeding them into R3.3A AI context.

**Tech Stack:** Unity 6000.0.76f1 ARM64, C#, Unity `JsonUtility`, NUnit EditMode/PlayMode tests, Python `unittest`, local JSON files under `Application.persistentDataPath`.

**Spec:** Approved R3.3B design and implementation authorization in the current task; prerequisite boundary is `EndangeredAR/docs/verification/2026-08-24-r3.3a-readonly-context-foundation.md`.

## Global Constraints

- Progress remains the only current-business source of truth; Memory never writes or repairs Progress.
- R3.3B does not modify `AIRequest`, AI prompts, Python routing, R2 grounding/citations, or R3 action and animation authorization.
- Only `AnimalDiscovered`, `MissionCompleted`, `KnowledgeLearned`, and `BadgeEarned` are supported events.
- Memory stores no chat text, LLM reply, prompt, nickname, user identity, device identifier, credential, path, or free-form model text.
- Production profile partition is fixed to `local-default`; no public API accepts arbitrary profile keys.
- A Progress save failure produces no committed state and no transition. A Memory failure never rolls back committed Progress.
- Every live event collection is capped at 64; `recentMilestones` is capped at 8.
- Unknown event strings remain raw persisted records but never project, fold, or execute. A higher document schema version is never overwritten.
- Every task uses RED, verifies the intended failure, applies minimal GREEN, runs focused tests, runs the full Python/EditMode/PlayMode gate, and commits one coherent change.
- Test artifacts are written to a caller-provided or ephemeral temporary directory outside the repository and are never committed. No runtime `character-memory.json`, Xcode export, or device container is committed.

public sealed class CharacterMemoryService : IAnimalProgressTransitionSink
